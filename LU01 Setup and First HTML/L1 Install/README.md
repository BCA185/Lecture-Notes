## Getting PC Read

- In file system (i.e., in the file explorer) change the settings to `show file externals` and `show hidden folders`
- Make a `IHCC>TERM>Beg Web>LU01` folder on Documents to keep class work in.
- If they have a Mac, make sure Safari has the `Develop` menu enabled in the `Advanced` settings.

## Software

- [Install VSCode](https://code.visualstudio.com/download)
- Add `Live Server` by Ritwick Dey
    - Add other extensions
- Add `Prettier` by Prettier
    - Change default formatter to Prettier in VSCode settings
- Enable `Auto Save` in VSCode settings
