# LU07: Grid Layout and Media Queries

In this unit you should learn:

- Responsive web design - a way to design websites so that they work on computer and mobile screens
- CSS Grid - a CSS layout tool like Flexbox that can control two dimensions at a time
- Media queries - these are special rules you can place in your CSS to apply new styles ONLY when the screen is a certain size
- More CSS selectors!
