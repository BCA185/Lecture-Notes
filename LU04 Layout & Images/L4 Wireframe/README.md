# L4 Wireframe OR James Example

## James Photo Gallery

Just spend time showing students the finished project and wireframe.
This website reuses the same header and footer on every page.
To avoid repeating the same code on every page, we use jQuery to load the HTML as a component.

In the `<head>` of each page, we include the jQuery.
We then use the `load()` function to load the header and footer HTML into the page.
This avoid copy and pasting the same code on every page.

**We will go into HOW to use jQuery later**
