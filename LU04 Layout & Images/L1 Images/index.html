Images in HTML

The <img> tag puts an image on a web page. It does not need a closing tag.

  • The src tells the browser where the image is.
  • The alt describes the image for people who cannot see it

Start with this:

<img src="image.jpg" alt="A description of the image">

Wrangling (Resizing) Images

Resize the Original Image First

Before you go and write CSS, first resize the original image using a photo editor. The image should never be bigger then the space it will be displayed in. A smaller image file loads faster.

Set a Fixed Width with CSS

You can change the width and height with pixels or percentages. Make sure to keep the aspect ratio.
