Which tool should I use?

  • CSS transition: move between two states, such as hover or focus.
  • CSS keyframes: describe repeating or multi-step motion.
  • JavaScript: start an effect after an event or control a changing value.

CSS motion here respects prefers-reduced-motion to trigger reduced motion. For JavaScript motion, Check the documentation for how to turn on reduced motion. animate().
