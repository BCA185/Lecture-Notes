Photo Gallery Example 2 (Light Box version 2 (2012) CSS, JavaScript and JQuery)

This example is an early version of a Photo Gallery that uses a Lightbox style. New effects that are added include a hover effect that has a light colored box around the thumbnail. After clicking on the thumbnail, the larger image appears using Javascript to add special effects of fading in. Controls are added to the larger image to open previous or next image. Also a close control is added that takes you back to the photo gallery.
