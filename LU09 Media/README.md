# LU09 Multimedia and JavaScript

In this unit you should learn:

- How to link videos to HTML
- How to embed external videos (Example: YouTube) to your HTML
- How to link audio to your HTML
- How to embed external audio (Example: SoundCloud) to your HTML
- Introduction to JavaScript, which allows you to execute code to change things on your website based on an event (click of a button, for example)
