Adding Structure by using HTML elements

We use the div html tag to create a container. A container is used to contain other elements, it is a way to help organize your elements. The div element is a block element. Block elements start on a new line and take up the full width available (stretches out to the left and right as far as it can).

Another container is created using the span tag. It is similar to the div except it is an inline element. Inline elements do not begin on new lines, but start from the next available position after the previous content on the same line. Inline content will also end at the end of the content.

New HTML5 Semantic elements have been created to add structure. These elements work similar to the div element but have specialized use. For example the nav element is used as a container for adding a navigation block. A header element is use to create a page heading. Also a footer element is used to add a block at the bottom of a web page.

Using CSS to add Style

CSS allows a web developer a method to format the web page. Some of the styles that can be set with CSS is color, text font, size of elements and position of elements.

Three methods to add CSS to an HTML document.

  • Inline
  • Internal
  • External

Internal styles are placed in the head section of the web page and is identified by the style tag and end style tag. Style rules are created using a selector followed by properties that are enclosed in curly braces. The selector identifies the HTML element that uses the properties identified after it. For example notice the header selector has background color.

You will notice that selectors can be of various types. Some selectors are the name of the HTML element. Other selectors might use an ID name, these will have a Hash tag in front of their name. Another type of selector uses a class name, and will have a dot in front of it in the internal style area. This paragraph has a class name that is used to add it's style.
