# Unit 3 Pair Programming

Stylize the HTML page with your external CSS. Be creative.

Use the following:

-   Add color
-   Change font
-   Make use of padding and margin.
-   Center some text or change things from block to inline or vice versa.
-   Optional: Move things around with flex box.

## Review:

Review a peer's HTML and CSS. Talk through your findings and discuss what you have noticed. Try and understand the developer's intent.

### Code review focus:

-   Functionality – does the page look like what the author intended?
-   Design – is the HTML and CSS well-designed?
-   Syntax – are there any syntax errors with the HTML and CSS?
-   Semantics – are the correct HTML tags being used?
-   Formatting – would another developer be able to easily understand and read the HTML and
    CSS?

### How to review

DON’T fix their HTML or CSS for them. Provide written feedback in
the form of a comment in their file.
Example:

```html
<!-- Reviewed by [your name] on [date]
Items to address:
1. …..
2. ….
3. …..
-->
```
