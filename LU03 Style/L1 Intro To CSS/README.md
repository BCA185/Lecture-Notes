## How to find HTML elements

In order to apply CSS to HTML elements you need to know how to find them.

Look [here](https://www.w3schools.com/CSS/css_selectors.asp) for the different ways to find HTML elements.

- By tag name
- By class name (`.className`)
- By ID name (`#idName`)
